# Project charter

## Historical purpose

AeroJudic was conceived as a graduate-course final-paper project exploring an aviation-violation investigation and adjudication domain.

## Verified current scope

- Java 21 and Spring Boot 3.5 backend structure.
- User, role, registration, login, JWT-oriented security, OpenAPI, and PostgreSQL dependency scaffolding.
- Basic Spring test structure with H2 test support.
- Vite/React frontend starter assets.

## Not currently implemented

- Violation reports, cases, investigations, hearings, decisions, penalties, documents, or workflow automation.
- An integrated frontend, domain data model, or complete application experience.
- Validated production identity, data-governance, operational, or regulatory controls.

## Portfolio decision

Do not feature this repository as a completed product. Retain as an archive/reference only, unless a future project charter funds and scopes a real implementation.
