## Status

The repository contains a Java 21/Spring Boot authentication scaffold and a separate Vite/React starter. It does not currently implement aviation-investigation workflows, case management, evidence/document handling, adjudication, or reporting.

It should be treated as a learning/archive candidate, not a showcase of a finished aviation-investigation product.
